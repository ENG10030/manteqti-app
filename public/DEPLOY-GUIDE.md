# ⚠️ تعليمات التحديث على Vercel - مهم جداً

## المشكلة: فقدان البيانات بعد التحديث
الإعلانات والتعديلات تختفي إذا تم استخدام أمر يحذف قاعدة البيانات.

## ✅ الطريقة الصحيحة للتحديث (بدون فقدان بيانات)

### الخطوة 1: رفع الكود على GitHub
ارفع الملفات الجديدة على GitHub repo الخاص بك

### الخطوة 2: تحديث قاعدة البيانات على Vercel
لو في تغييرات في prisma/schema.prisma، نفذ هذا الأمر:
```
npx prisma db push
```
⚠️ هذا الأمر يضيف الجداول والأعمدة الجديدة فقط - لا يحذف أي بيانات موجودة!

### ❌ أوامر ممنوعة تماماً (تحذف البيانات):
- `prisma migrate reset` - يحذف كل البيانات!
- `prisma db seed` - يحذف البيانات القديمة!
- حذف وإعادة إنشاء قاعدة البيانات على Neon/Supabase

## لو البيانات اتمحلت بالفعل:
للأسف لا يمكن استرجاع البيانات المحذوفة من قاعدة البيانات
- الإعلانات: لازم تنشرها من جديد
- المستخدمين: لازم يسجلوا من جديد

## للنسخ الاحتياطي مستقبلاً:
```
npx prisma db pull --print
```
أو من لوحة تحكم Neon/Supabase: التصدير > تصدير البيانات
